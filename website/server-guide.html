01 / BUYING A COMPUTER

What should you buy?

For a small office, a refurbished business mini PC or a modern mini PC is often enough to start. The aim is reliability, not gaming performance.

THE EVERYDAY CHOICE

Small business server

A practical starting point for a small team and ordinary bookkeeping workloads.

Processor
Modern Core i3/i5 or Ryzen 3/5 equivalent
Memory
16 GB RAM
Drive
500/512 GB SSD
System
Windows 11 + Gigabit Ethernet
Recommended purchase target, not a measured minimum.
MORE ROOM TO GROW

Busy or multi-business server

If you have lots of organisations, larger reports or frequent data imports.

Processor
Recent Core i5/i7 or Ryzen 5/7
Memory
32 GB RAM (upgradeable)
Drive
1 TB NVMe SSD or more
Network
Wired connection + backup power
Size for measured workloads and storage growth.
KEEP THE COST DOWN

Refurbished office mini PC

Often a better buy than a new low-end device. Check its age and condition.

Windows
Official Windows 11 compatibility and valid licence
Condition
Healthy SSD, working fan and included power adapter
Upgrade
16 GB RAM, replaceable storage and Ethernet
Protection
Warranty or return policy
Avoid Windows 10-only machines for new deployments.
Spend on reliability first.

You do not need a dedicated graphics card or a rack server. Leave room in your budget for an independent backup drive and ideally a UPS to keep the PC and router alive through short outages.

02 / INSTALL Tohyee

From new computer
to running server.

These steps follow the project's Windows installer. No separate PostgreSQL installation is needed.

  1. 01

    Get Windows ready

    Install supported Windows 11 updates. Connect Ethernet, keep Windows Defender and the firewall enabled, and set sleep to Never when plugged in. The screen can still turn off. Put the PC somewhere dry, cool and secure.

  2. 02

    Download the official installer

    Visit Tohyee's GitHub releases, read the latest release notes, and download TohyeeSetup-<version>.exe. Don't download a third-party installer.

  3. 03

    Install and create your admin

    Run the installer. It creates two Windows services, Tohyee and TohyeePostgres, that start with Windows, even before sign-in. Keep the installation's private setup token, then open http://localhost:3000 on that computer and create your first admin login.

  4. 04

    Open server settings

    Use the Tohyee server icon near the Windows clock or Tohyee server settings in the Start menu. Add your first organisation, or try the fictional demo farm first. Choose modules and user access.

  5. 05

    Set up secure access

    For people away from the office, use Remote access in the server app. A Cloudflare Tunnel with your own domain or Tailscale Funnel provides HTTPS without router port forwarding. Configure two-step sign-in and recovery email, then test with a phone on mobile data.

    The project's managed Tohyee address service is not operating yet. Do not rely on it. Never forward PostgreSQL port 5432 or expose plain HTTP to the internet.

  6. 06

    Protect the books before using them

    Choose a backup destination, run Back up now, confirm the file exists and actually reached any cloud account, then save the recovery kit separately. Check the kit and test restoring a copy. Tohyee makes encrypted nightly backups, but you are responsible for verified off-site copies.

  7. 07

    Test a restart

    Restart Windows and confirm Tohyee works without signing into the PC. Try a different browser or phone, check backups, keep software updated and monitor available storage.

03 / KEEP IT HEALTHY

Remember the boring bits.
They're important.

↻

Backups you can restore

Tohyee keeps 14 daily and 12 monthly encrypted backups by default. Keep the recovery kit away from those files, confirm cloud sync and practise a restore.

⏻

Power that stays on

Disable automatic sleep, keep the router connected and consider a UPS. A machine that shuts down or loses internet can't serve remote users.

⌁

Secure remote access

Keep Windows patched. Use HTTPS, two-step sign-in and least-privilege accounts, not an open database port or public router forwarding.

Tohyee is still under development. Actual performance depends on your organisation count, concurrent users, imported files and reports. Check the feature register and limitations before deploying business-critical workflows.
