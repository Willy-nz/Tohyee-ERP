Setup guide

Set up a Tohyee server.

Buy a sensible computer, install Tohyee and set up backups. No special IT equipment needed.

Step 1

Which computer to buy.

Avoid machines that only run Windows 10.

Spend on reliability first. You don't need a graphics card or a rack server. Leave money for a separate backup drive and, ideally, a UPS to keep the PC and router running through short power cuts.

Step 2

Install Tohyee.

These steps follow the Windows installer. You don't need to install PostgreSQL separately.

  1. Get Windows ready

    Install Windows 11 updates. Connect Ethernet, keep Windows Defender and the firewall on, and set sleep to Never when plugged in. The screen can still turn off. Keep the PC somewhere dry, cool and secure.

  2. Download the installer

    Go to Tohyee's GitHub releases, read the release notes, and download TohyeeSetup-<version>.exe. Don't use an installer from anywhere else.

  3. Install and create your admin

    Run the installer. It adds two Windows services, Tohyee and TohyeePostgres, which start with Windows, even before anyone signs in. Keep the private setup token, then open http://localhost:3000 on that computer and create your first admin login.

  4. Open server settings

    Use the Tohyee icon near the Windows clock, or Tohyee server settings in the Start menu. Add your first organisation, or try the fictional demo farm first. Choose modules and who can use them.

  5. Set up secure access

    For people away from the office, use Remote access in the server app. A Cloudflare Tunnel with your own domain, or Tailscale Funnel, gives you HTTPS without opening ports on your router. Turn on two-step sign-in and a recovery email, then test from a phone on mobile data.

    The Tohyee-hosted address service isn't running yet, so don't rely on it. Never open PostgreSQL's port 5432 or plain HTTP to the internet.

  6. Back up before you start

    Choose a backup folder, run Back up now, and check the file exists and has reached any cloud account. Save the recovery kit somewhere separate, then test restoring a copy. Tohyee makes encrypted nightly backups, but keeping a checked off-site copy is up to you.

  7. Test a restart

    Restart Windows and check Tohyee works without signing in to the PC. Try another browser or a phone. Keep software updated and watch the free disk space.

Step 3

Keep it running.

Backups you can restore

Tohyee keeps 14 daily and 12 monthly encrypted backups. Store the recovery kit apart from them, check cloud sync and practise a restore.

Power that stays on

Turn off automatic sleep, keep the router on and consider a UPS. A computer that's off can't serve anyone.

Safe remote access

Keep Windows updated. Use HTTPS, two-step sign-in and only the access people need. Never open the database to the internet.

Tohyee is still being developed. Speed depends on how many organisations, people, imports and reports you have. Check the feature list and limits before relying on it for important work.
