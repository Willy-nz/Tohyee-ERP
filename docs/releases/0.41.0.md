# Tohyee 0.41.0

Everything merged since 0.40.0. 0.39.0 and 0.40.0 weren't published on their own, so updating from 0.38.0 to 0.41.0 brings in [0.39.0's](0.39.0.md) and [0.40.0's](0.40.0.md) changes too.

## Before you update

- **No database changes in this release.** (0.39.0 and 0.40.0 have theirs: see their notes.)
- **Data sources and Prepare data are now for bookkeepers and up.** Someone with the Viewer role still sees Reports, and no longer sees where the data comes from or how it's shaped.
- **Not checked on Windows:** the Analytics lock fix below was proven and tested on Linux. If the message comes back after updating, please report it.

## Fixed

- **Analytics "locked by another Tohyee process".** On a Windows server a refresh could keep failing with this message when nothing was left running. Tohyee was opening its own analytics file twice and Windows refused the second. It now opens it once. If Tohyee ever does hold its own file again, the message says so.

## New

- **Farm pictures:** 35 illustrated pictures on every Log button, the Log, Chat and More tabs, the Farm menu and each kind of calendar job. They're kept on the phone for use offline.
- **Farm Today** opens with three figures: average cover, head in paddocks and jobs today.
- **Search on Invoices and Bills:** by number, customer or supplier, or reference. It searches every record, not just the ones on screen.
- **CRM Dashboard:** four headline figures, and a bar for each stage of the pipeline (on Home too).
- **Releases publish themselves** when a version bump merges.

## Changed

- **Pasture and feed** is four tabs (Cover, Grazings, Feed, Readings) instead of one long page.
- **Livestock** head count leaves out a movement column nobody used that year. How closing is worked out is behind the info button.
- **Farm › More** has the everyday pages first, with year end and money together.
- **Bank account:** Reconcile, Statement lines and Bank transactions are tabs; the rest are under More.
- **Home's bank tile** is the balance and one reconcile link, which opens that account.
- **Bank accounts:** the Stripe, PayPal, Wise and overseas bank set-ups fold to a line each.
- **Shorter descriptions** on farm cards, with the detail behind info buttons.
- Internal reference codes no longer show on the Livestock screens.
