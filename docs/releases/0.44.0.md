# Tohyee 0.44.0

Everything merged since 0.43.0.

## Before you update

- **Database changes:** one for the server (0030, a table for chart mapping) and one for each organisation (0307, a farm's "Windy from" figure). Nothing existing is changed. Back up first, as for any update.
- **Update now** needs this version on the server before it can be used: 0.44.0 is the first with the updater, so this update is still installed the usual way.
- **Not tried on a real Windows computer:** Update now. **Not tried against MetService's live service:** cloud cover.
- **Not yet reviewed by the owner:** the sun and cloud cut-offs (WX13) and the consolidation rules added here (CO15, CO16), written up in `docs/ACCOUNTING-EXAMPLES.md`.

## New

- **Update now in Tohyee:** a server admin can update a Windows server from any device, from their menu, without signing in to the server computer. Tohyee backs everything up first, then installs GitHub's latest release after checking its SHA-256.
- **Consolidation: chart mapping.** In a group, a new Chart mapping tab sends each account of an organisation to one of the parent's accounts of the same kind, so offices with different charts of accounts add up on the parent's lines. It opens on the accounts with nowhere to go and can match them by name. AI keys can read the mapping, and a Full access key can set it.
- **Farm weather pictures:** each day in the forecast shows Frost, Rain or Windy with its word. Windy is from each farm's own "Windy from" figure (40 km/h unless changed; gusts count at half as much again). Tick **Cloud** in weather setup (one more MetService unit a farm at each refresh) for Sunny, Some cloud and Cloudy on dry days.

## Fixed

- **Consolidation:**
  - An account whose code was a different kind of account in another organisation (an asset in one, an expense in another) was left out of its report, and the consolidated balance sheet didn't balance. Each kind now has its own line, with a notice.
  - The Rates tab showed 1.000000 for a month the parent's list has no rate for. It now shows no rate.
  - A rate from a set was used past the end of its period.
  - Budget vs actual now ends in net profit; its total used to add income and costs together.
  - The report heading said "Organisation" when a group was opened from a member other than the parent.

## Changed

- **Consolidation:** notices name codes that have different names in different organisations; a missing exchange rate is said once a currency with the date that fixes it; an intercompany difference between currencies says it can be the rate moving; blank cells are left out on phones; Make a group starts from the organisation you're in.
- **Spreading:** rules SW1 to SW25 are recorded as accepted by the owner.
- Dependency updates (mail, PDF and database libraries, build tools).
