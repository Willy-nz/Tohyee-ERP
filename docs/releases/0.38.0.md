# Tohyee 0.38.0

Everything merged since 0.37.0.

## Before you update

- **The database updates itself when Tohyee starts.** This release adds tenant migration 0290 (Payroll as an add-on). Existing organisations keep payroll on wherever Accounting is on.
- **Not yet reviewed:** account order within a group (CR26), report pictures and dark cards (PIC1–PIC6, PBG1, DTX1), Payroll as an add-on (PAO1–PAO9) and employees from a file (EMI1–EMI8) follow common practice.
- **Not tried for real:** the one-step PowerPoint setup for Windows hasn't been run on a real Windows PC yet.

## New

- **Payroll as an add-on:** a Payroll switch under Modules. With Accounting on, payroll stays in Accounting's Payroll menu and posts to the books. With Accounting off, Payroll is its own app: pay runs work out PAYE, KiwiSaver, ESCT and student loan, with payslips and payday filing, but nothing posts. Pay runs from that time stay history if Accounting is turned on later.
- **Bring in employees from a file:** a CSV or Excel export from an HR system such as BambooHR, or a spreadsheet. Columns are matched by heading; what the file hasn't got (tax code, KiwiSaver, pay frequency) is chosen once, never assumed. Preview first.
- **Account order within a group:** drag accounts, or move them up and down, in a custom report layout.
- **Heading size** in the Analytics heading editor.
- **AI and report pictures:** the AI sees backgrounds and picture tiles, can fade, move or remove them, and can use a photo left in Files for your AI or a picture already on a report. A removed picture comes back when History puts back an earlier version.
- **PowerPoint add-in:** one page per slide, scaled to fit (a long page scrolls instead of shrinking too far), ‹ › to change page, and a one-step setup for PowerPoint on Windows.

## Fixed

- **Analytics on phones:** a report with several pages no longer runs off the right side of the screen; the page tabs scroll in their own row.
- **Cover photos** fill the page instead of showing as a strip.
- **Words on dark cards** are light, unless a colour was chosen for them.
- **The Employees screen** no longer says payroll tax isn't worked out.
