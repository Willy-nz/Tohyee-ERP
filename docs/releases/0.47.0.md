# Tohyee 0.47.0

Everything merged since 0.46.0.

## Before you update

- **Database changes:** one for each organisation (0320, chats and who's in them). The team chat becomes the first space, "Everyone": its messages, photos, voice notes and how far each person has read all carry over. The old table of who has read what is copied across, then removed. Back up first, as for any update.
- **Chat is still off until an admin turns it on** (Settings › Modules), as before.
- **Owners and admins can read any chat** if they need to. Every direct message and space says so, and each time one is opened in Review chats it's recorded in the audit trail. Tell your team before they start using direct messages.
- **Not yet tried in a browser or on a phone:** the new Chat screens. They're covered by tests only.
- **Not yet reviewed by the owner:** the details in TCH10-TCH27 in `docs/ACCOUNTING-EXAMPLES.md`.
- **Releases aren't signed yet**, and Update now is **not yet tried on a real Windows computer** (see the 0.46.0 notes).

## New

- **Chat: direct messages, spaces and mentions.**
  - **A list of chats:** Home (the latest from every chat you're in), Mentions, Direct messages, then Spaces, each with its unread count. On a phone the list comes first and a chat opens on its own.
  - **Direct messages:** one to one, or a group of up to 12. The same people always get the same chat.
  - **Spaces:** named group chats anyone in Chat can make. Members add people and can leave; whoever made it, an owner or an admin can rename or close it. A closed space stays readable.
  - **Farm chats** show as spaces for the people who already have them. Farm staff are unchanged: their farm's chat only.
  - **Mentions:** type @ to pick someone in the chat. It shows under Mentions until they've read it.
  - **Review chats** (owners and admins): read a chat you're not in, with no unread counts and no posting. Every chat, photo or voice note opened there goes in the audit trail.
  - **The AI:** a person's own AI connection can list, read and post only in the chats that person is in. It can't use Review chats.

## Changed

- **Viewers can chat like everyone else.** Being a viewer limits the books, not Chat: they can post, start direct messages, make spaces and be mentioned. In a farm's chat they still only read. Report viewers and farm staff aren't in Chat.
- The Chat app's unread badge now counts every chat you're in, farm chats included.
