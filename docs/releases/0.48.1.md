# Tohyee 0.48.1

One fix since 0.48.0, for the Android app (#117).

## Before you update

- **Database changes:** none.
- **Only the Android app changes.** The server is the same as 0.48.0.
- **The Android app is still a test build** ("Tohyee (test)"). A newer test build can't be installed over an older one: uninstall the old one first, then install this one and enter your Tohyee address again.
- **Not yet tried on a phone.** The cause was found by reading the code, and the automated emulator check doesn't press Open Tohyee.
- Everything in the 0.48.0 notes still applies, including that the backup server hasn't been tried on two real computers.

## Fixed

- **Android app: Open Tohyee closed the app.** On the first screen, after Check found the server, pressing Open Tohyee stopped the app. The app read the page's address in a way Android doesn't allow. It now keeps the address and opens your Tohyee.

## Known, not fixed

- If the server answers a page with an error (a link to a page that isn't there, say), the Android app shows "Can't reach Tohyee" even though the server is fine. Try again goes back to Tohyee.
